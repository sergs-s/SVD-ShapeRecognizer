# tools/verify – независимая сверка мер по файлам оценок

Задача №1 от 19.10.2026, (б): меры отчётов `XBaseEval` пересчитываются отдельной программой на Python по файлам оценок,
без Java-кода мер. Определения взяты из CLAUDE.md и PLAN.md; места, где соглашение взято из кода, отмечены в
`measures.py` с файлом и строкой.

Зависимости: Python 3, numpy, scipy (`scipy.special.betaincinv` для границы Клоппера – Пирсона).

- `measures.py` – d₁/d₂ (правило вырожденных случаев), выбор модели X / X+mirror по позе пробы, порог Неймана – Пирсона
  (П2, «разд.»), П3 (КП по n_eff), deff, EER, все меры строки при весах людей (бутстреп).
- `compare.py <набор> [B] [вывод]` – сверка всех ячеек разделов «Сводка», «Ошибка своих, разложение», «FAR контроля при
  П2 и П3», «Разделимость: точка равных ошибок» (θ, ошибка, FAR), «Парные разности» и «Парные разности разделимости».
  Наборы: `orl`, `muct`, `gt-subsp`, `gt-xs-f` (каталог SVD-faces-data – `VERIFY_DATA`), `feret-xs2`, `feret-subsp`,
  `feret-mp2` (клон SVD-feret-cloud – `VERIFY_FERET`). Точки сверяются как строки отчёта, концы интервалов – с допуском
  ±2 п. п.
- `update_check.py update|wstatus4 [вывод]` – feret-update и feret-wstatus4: точки сводки, вычислимые из файла оценок.

Переключатель `measures.P3_ZERO_W` (по умолчанию выключен) – вариант порога П3 в репликах бутстрепа «как в коде»: в поиске
участвуют попытки людей с нулевым весом (FeiThreshold.java:117, 121, 131–133). Итоги сверки – в
`SVD-faces-data/reports/verify_<код>/`.
