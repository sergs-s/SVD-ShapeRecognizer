## 1. Что сделано (v1.0-sigma — стабильная версия)

### Функциональность
- Полная цепочка распознавания: предобработка → σ-вектор → классификация.
- **ImagePreprocessor** — конвейер 64×64, три ветки выравнивания «Путь B».
- **SVDComputer** — σ-вектор (20 нормированных сингулярных значений).
- **ShapeRecognizer** — классификатор, метод «Путь B», евклидово расстояние.
- **TemplateStore** — хранилище эталонов, автоматический пересчёт среднего σ-вектора.
- **TemplateRepository** — сериализация эталонов в `templates/*.dat`.
- **SettingsStore** — три порога классов в `settings.properties`.
- Полный Swing-интерфейс: загрузка, управление эталонами, вывод результата.

### Качество
- На контрольном наборе **22 фигуры** — безошибочная классификация.
- Проверено распознавание фигур вне обучающего набора — корректно.
- Код задокументирован в стандарте Javadoc.

### Структура репозитория (v1.0-sigma)
```
svd.recognizer
├── math        — SvdEngine, CommonsMathSvdEngine, SvdResult
├── processing  — ImagePreprocessor, SVDComputer, ShapeRecognizer
├── model       — ShapeClass, Template, TemplateStore
```

## 3. Следующий этап — метод SVD-подпространств (eigenshapes)

**Ветка:** `svd-subspaces`  
**ТЗ:** `TZ_dlia_programmistov_podprostranstva-8.docx`  
**Чек-лист:** `Poriadok_raboty_cheklist-2.docx`

### Идея
Вместо сравнения σ-векторов — сравнение **полного изображения** (4096-мерного
вектора пикселей) с **линейным подпространством класса** по **ошибке реконструкции**:

```
ε = ‖x′ − BB⊤x′‖,  где  x′ = x − mean
```

Ответ: тот класс, у которого ε минимальна и ε < θ (единый порог отвержения).

### Архитектурный принцип
Существующий код v1.0-sigma **не удаляется**. Новый метод добавляется как
**параллельный режим** (переключатель `RecognitionMode: SIGMA_VECTOR / SUBSPACE`).

### Новые классы (план)

| Класс | Пакет | Статус |

### Критерии приёмки нового этапа
1. Все 22 фигуры классифицируются верно методом отложенного контроля (k = 4).
2. Идеальная фигура из графического редактора (square7) распознаётся корректно.
3. Посторонние изображения → «не распознано» при θ ≈ 13.
4. После «Обучения» и перезапуска программы подпространства загружаются без повтора обучения.
5. σ-режим работает как прежде — регрессий нет.

## 5. Перспектива

Метод подпространств, реализуемый в `svd-subspaces`, математически совпадает с
методом **eigenfaces**. При переходе к распознаванию лиц изменится только
содержание классов — аппарат (центрирование, SVD-базис, ошибка реконструкции)
остаётся тем же. Таким образом, текущий этап является прямой инфраструктурной
подготовкой к следующей стратегической цели проекта.
