# SVD Shape Recognizer

Итоговый проект собран с нуля по архитектуре:
- `svd.recognizer.math` содержит `SvdResult`, `SvdEngine`, `CommonsMathSvdEngine`;
- `SVDComputer` работает через `SvdEngine`;
- GUI состоит из двух форм: `MainFrame` и `TemplatesFrame`;
- `MainFrame` содержит `RecognitionPanel`;
- `TemplatesFrame` содержит `TemplatesPanel`;
- шаблоны хранятся в корневой папке `templates`;
- `.dat` файлы созданы пустыми.
