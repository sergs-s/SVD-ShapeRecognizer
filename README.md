# SVD-ShapeRecognizer

Распознавание рукописных геометрических фигур (круг, треугольник, прямоугольник)
методом сингулярного разложения (SVD). Учебный проект — методический шаг к
распознаванию лиц методом собственных лиц (eigenfaces).

## Возможности

- Предобработка произвольного снимка фигуры: устранение фона, шума, наклона и
  масштаба, приведение к нормализованному изображению 64×64.
- Вычисление компактной SVD-подписи формы (σ-вектор).
- Классификация фигуры по трём классам или вывод «не распознано».
- Графический интерфейс (Swing): загрузка изображений, управление обучающим
  набором эталонов, настройка порогов, отображение результата.

## Технологии

- **Java** (сборка под Java 26)
- **Maven** — система сборки
- **OpenCV** (`org.openpnp:opencv`) — обработка изображений
- **Apache Commons Math** — сингулярное разложение
- **Swing** (формы NetBeans) — графический интерфейс

## Сборка и запуск

```bash
mvn compile              # компиляция
mvn javadoc:javadoc      # генерация HTML-документации (target/site/apidocs)
mvn test                 # модульные тесты
```

Запуск приложения — через главный класс `svd.recognizer.Main` (из IDE или
`mvn exec:java`). Перед запуском нативная библиотека OpenCV загружается
автоматически в классе `Main`.

## Как работает распознавание (кратко)

1. **Предобработка** приводит изображение к нормализованному виду 64×64.
2. **σ-вектор** — первые 20 сингулярных значений матрицы изображения,
   нормированных по первому; служит «подписью» формы.
3. **Классификация (метод «Путь B»)** — неизвестная фигура обрабатывается тремя
   ветками (как круг, как треугольник, как прямоугольник), каждая гипотеза
   сравнивается со средним σ-вектором своего класса по евклидову расстоянию;
   выбирается ближайший класс, прошедший свой порог, иначе — «не распознано».

«Обучение» в текущей версии — это автоматическое усреднение σ-векторов эталонов
при их добавлении.

## Статус и развитие

Текущая версия (классификация по σ-вектору) стабильна: на контрольном наборе
из 22 фигур — безошибочная классификация. Зафиксирована тегом `v1.0-sigma`.

Следующий этап — переход на метод собственных подпространств (eigenshapes):
классификация по ошибке реконструкции в подпространстве класса. Устраняет
ограничения σ-вектора (распознавание идеальных фигур, отсев посторонних
изображений) и является прямой подготовкой к распознаванию лиц (eigenfaces).
Ведётся в ветке `svd-subspaces`.
