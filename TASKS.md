## Решения по вопросам шага 4

1. **Освещение** — решено: базовый прогон без нормализации; эквализация
   гистограммы — отдельным вариантом для сравнения на том же разбиении.
2. **Фигуры и лица** — решено: фигуры остаются в той же ветке; лица —
   отдельный пакет; ядро `SubspaceTrainer`/`SubspaceRecognizer` обобщается на
   произвольную длину вектора (сейчас рассчитано на 64 × 64 = 4096, у ORL
   92 × 112 = 10 304).
3. **Читатель PGM** — решено: грузим через OpenCV (`Imgcodecs.imread`), свой
   читатель не пишем — на шаге 5 всё равно будет JPEG через OpenCV.
4. **Цели и выбор порога** — решено: применение — контроль доступа, худшая
   ошибка — принять чужого. Критерий Неймана – Пирсона: θ выбирается на
   валидационной части при ограничении FAR ≤ α, в отчёт — FRR при этом θ.
   Значение α задаётся после первого прогона. На контрольной части порог не
   подбирается.
5. **Где фиксировать решения** — решено: отдельного документа `.docx` не
   делаем. Рабочие решения фиксируются здесь, в `TASKS.md`; устоявшиеся
   правила, обязательные для каждой сессии, переносятся в `CLAUDE.md`;
   математика и протокол остаются в плане работ
   (`Переход к распознаванию лиц план работ.docx`). Итоговый формальный
   документ — при необходимости, в конце этапа лиц.

## Решения по итогам базового прогона (Жорик, 26.09.2026)

1. Рабочее α = 0,05 для сравнения вариантов на ORL; операционное α задаётся
   позже на своей базе и будет жёстким (контроль доступа, худшая ошибка —
   допуск чужого).
2. Базовая конфигурация дальше: без нормализации освещения; общий порог по
   объединённой валидации всех фолдов (Нейман – Пирсон, на контроле не
   подбирается); основной скоринг — ε₁/ε₂ (лучшее к второму), ε выводится
   рядом для сравнения.
3. Ограничение ε₁/ε₂: оценка зависит от состава галереи (второй кандидат),
   порог калибруется заново при любом изменении списка людей; при галерее из
   одного человека скоринг не определён; порог с ORL на свою базу не
   переносится.
4. FAR выводится и по попыткам, и по людям (чужой принят, если принят хотя бы
   один его снимок), с верхней 95 % границей Клоппера – Пирсона.
5. Нюанс объединённой валидации (часть своих фолда участвует в ней как чужие)
   признан пренебрежимым: разрыв FRR групп тот же, что при пороге по фолду.

## Критерий «готово» для шага 4

- Проект компилируется в NetBeans, GUI открывается дизайнером (.java/.form синхронны).
- База ORL загружается из папки без ручной подготовки.
- Оценка по протоколу запускается одной командой, результат воспроизводится
  (фиксированный seed).
- Отчёт содержит все метрики протокола, θ, выбранный по критерию
  Неймана – Пирсона (FAR ≤ α на валидации), FRR при этом θ на контроле,
  выбранное η, сравнение «единый k» / «k_c по энергии» и базового варианта
  с эквализацией гистограммы.
- Режим фигур работает как раньше (решение по вопросу 2).
